> Это средство перехвата и фильтрации сетевого трафика, требуемое для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские программы. В результате файл удаляется и отправляется в карантин. Название обнаружения обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите поиск PUA (потенциально нежелательных приложений). В Kaspersky, например, есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При корректном понимании настроек лучше добавить исключение, а если вы не уверены в своих действиях, отключите обнаружение PUA.

## ⚙️Установка и использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в настройках самой системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Glowaearouse/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, это действие не требуется

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий скрипт
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, перейдите в **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Что делает каждый файл

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и остальные), пока не найдёте подходящую**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - смена режима обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - изменение режима обработки сервисов из `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который напрямую, без zapret, не открывается  
  В скобках показывается статус:
    - `none` - ни один IP не проверяется
    - `loaded` - проверяется, входит ли IP в список
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - получение свежего `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - ручная проверка новой версии
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret не запускается или не работает.  
  В конце процедуры можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` не видно никаких изменений

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe (обход).  
Если процесс не появился, обратитесь к [#522](https://github.com/Glowaearouse/zapret-discord-youtube/issues/522)

### Рабочей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - От имени администратора откройте текстовым редактором файл `hosts` в созданном каталоге
  - Вставьте скопированное содержимое в конец `hosts` либо замените прежний аналогичный фрагмент
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа функции не гарантируется. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) через [локальный прокси](https://github.com/Glowaearouse/tg-ws-proxy) или любой публичный прокси.

### Обход не запускается или прекратил работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Даже подходящий вариант может перестать работать после того, как его обнаружат.
> В репозитории собрано много стратегий обхода. Если ни одна не помогает, создайте новую на основе одной из существующих и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте вывод `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что домен или IP нужного ресурса присутствует в соответствующих списках

- Переключитесь на другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Glowaearouse/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Затем запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце ответьте Y
- Удалите старую папку с zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/Glowaearouse/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть "Разблокировать", включите параметр, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте нужные интернет-ресурсы. Если вариант не работает, закройте программу через значок замка в панели задач и выберите другую стратегию
- После выбора рабочего варианта включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ним бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. [#251](https://github.com/Glowaearouse/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузер тоже не подключается, снова проверьте остальные стратегии: YouTube и Discord могут требовать разные варианты
- См. [#252](https://github.com/Glowaearouse/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Glowaearouse/tg-ws-proxy)
- Либо подключитесь через бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игры используют разные сетевые схемы, поэтому проверить и исправить каждую из них невозможно.

Обычно следует сделать так:
- обновить ipset через `service.bat` и включить `Game Filter`
- если это не помогло, дополнительно включить `ipset any`

Учитывайте, что `ipset any` может нарушить доступ к большому числу сайтов. Не оставляйте этот режим включённым постоянно: выясните IP-адреса игры и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Glowaearouse/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Оформите обращение [здесь](https://github.com/Glowaearouse/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не следует
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`
